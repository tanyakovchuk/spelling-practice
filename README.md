# Spelling Practice

Тренажер правопису англійських слів: слухаєш слово, пишеш його з пам'яті, бачиш посимвольний розбір помилок і оцінку.

**[▶ Відкрити застосунок](https://tanyakovchuk.github.io/spelling-practice/)**{target="_blank" rel="noopener noreferrer"}

Онлайн-версія: <a href="https://tanyakovchuk.github.io/spelling-practice/" target="_blank" rel="noopener noreferrer">https://tanyakovchuk.github.io/spelling-practice/</a>

## Можливості

- Озвучення слів через Web Speech API (вибір голосу, повільний режим).
- Введення списку слів з нового рядка, через кому, пробіл або `слово - переклад`.
- Автоматичний переклад (MyMemory API) з кешуванням у `localStorage`, або власний переклад через тире.
- Посимвольне порівняння (відстань Левенштейна): підсвітка правильних, зайвих, пропущених і замінених літер.
- Коло повторення слів, у яких була помилка.
- Підсумок: успішність, оцінка 1–12, кількість спроб, список слів.

## Запуск

Статичний сайт без збірки — достатньо відкрити `index.html` у браузері.

```bash
npx serve .
```
